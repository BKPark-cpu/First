# 05. 운영자 매뉴얼 — 수주·매출 실적 마감 및 경영실적 보고서

> 대상: **시스템 관리자** · 버전 v1.0 (2026-10-01)
> 전제: Windows PC 또는 재무 공유 폴더에 `task/` 폴더를 둠 (PowerShell 5.1 기본 탑재, 추가 설치 없음)

## 2. 폴더 구조와 파일 관리

```
task/
├─ input/                     ← 운영 데이터 (저장소에 올리지 않음)
│  ├─ 수주실적.csv · 매출실적.csv · 손익실적.csv   (매월 교체)
│  ├─ 제품군매핑.csv · 사업계획.csv               (마스터)
│  ├─ 마감이력.csv (+ .bak)                       ← 스크립트 관리. 직접 수정 금지
│  └─ closed/YYYYMM/ (+ vN/)                      ← 마감 스냅샷. 삭제·수정 금지
└─ output/YYYYMM/                                 ← 결과. 언제든 다시 만들 수 있음
   └─ 확정/                                       ← 확정본 (배포·보관용)
```

- **백업 대상:** `input/마감이력.csv`, `input/closed/`, `output/*/확정/`. 이 세 가지가 있으면 과거 확정 보고서를 그대로 다시 만들 수 있습니다.
- `output/` 의 나머지는 지워도 `run.bat` 으로 다시 만들어집니다.

## 3. 일상 운영

### 3-1. 월 마감 일정 (권장)

| 시점 | 작업 | 담당 |
|------|------|------|
| M+1월 1~2영업일 | 수주·매출 원장 내려받기 → `run.bat` → 오류 정정 요청 | 재무 |
| M+1월 3영업일 | 더존 결산 손익 입력 → `run.bat` → 숫자 검토 | 재무 |
| M+1월 4~5영업일 | `run_close.bat` → 확정본 배포 | 재무 |

### 3-2. 실행 결과 읽는 법 (콘솔)

| 출력 | 의미 |
|------|------|
| `[2026-02] 초안 (미마감)` | 정상 실행, 미마감 |
| `검증: 오류 N건 · 경고 M건` | `output/YYYYMM/검증결과.csv` 참고 |
| `마감 완료: 2026-02 확정 v1 (수주 n건 · 매출 m건, 해시 …)` | 마감 성공 |
| `마감 실패: …` (종료 코드 2) | 사유가 함께 나옴. 보고서는 초안으로 생성 |
| `재오픈 완료: 2026-02 (확정 v1 보관 → …\v1)` | 재오픈 성공 |
| `[수주실적] 'date' 열을 찾지 못했습니다 …` | 실제 헤더가 함께 나옴 → `config.json` 후보 추가 |

### 3-3. 배치 파일 정리

| 파일 | 하는 일 | 원본 수정 | 마감이력 |
|------|------|:---:|:---:|
| `run.bat [yyyy-MM]` | 검증 + 보고서 초안 (월 생략 시 전월) | 없음 | 변화 없음 |
| `run_close.bat yyyy-MM` | 마감 (오류 0건일 때만) | 없음 | **추가** |
| `run_reopen.bat yyyy-MM "사유"` | 최근 마감월 재오픈 | 없음 | **추가** |
| `run_sample.bat` | 샘플로 실행 (2026-02 고정) | 없음 | 없음 |
| `run_selftest.bat` | 단위 테스트 24건 | 없음 | 없음 |

## 4. 운영 작업

### 4-1. 제품군 명칭·분류가 바뀔 때

원장이나 보고서 양식을 고치지 않고 **`제품군매핑.csv` 만** 수정합니다.

| 상황 | 매핑 작업 |
|------|-----------|
| 명칭 변경 (전자문서 → 위변조방지, 2026-01부터) | 기존 행 `전자문서→전자문서` 에 `적용종료월=2025-12`. 새 행 `전자문서→위변조방지, 적용시작월=2026-01`. 원장에 새 이름이 나오면 `위변조방지→위변조방지, 2026-01~` 추가 |
| 제품군 통합 (모바일보안·콘텐츠보안을 DRM으로, 2026-04부터) | `모바일보안→모바일보안` 종료 2026-03 + `모바일보안→DRM` 시작 2026-04 (콘텐츠보안도 같은 방식) |
| 단종·소규모 제품 | `CMT→기타` 처럼 묶음 행으로 연결 |
| 신규 제품군 | 행 추가 + `정렬순서` 지정. 필요하면 `사업계획.csv` 에 제품군 목표 추가 |

- 기본(`mappingBasis = report`)은 **보고월의 체계로 과거 3개년까지 다시 분류**합니다. 통합 이후 보고서의 전년 DRM에는 전년 모바일보안·콘텐츠보안이 포함됩니다.
- 과거 보고서와 같은 체계로 비교해야 하면 `config.json` 에서 `"mappingBasis": "transaction"` 으로 바꿉니다. 다만 이 경우 전년 비교가 서로 다른 체계끼리의 비교가 됩니다.
- 마감 스냅샷에는 **원천제품군**이 저장되므로, 매핑만 바꾸면 마감된 달의 보고서도 새 체계로 다시 만들어집니다. 마감 해시는 바뀌지 않습니다.

### 4-2. 재오픈 승인

- 재오픈은 이력에 남습니다(일시·실행자·사유). 재오픈 요청은 메일 등으로 받고, 사유를 그대로 `-Reason` 에 적습니다.
- 앞선 달을 고쳐야 하면 **최근 달부터 역순으로** 재오픈하고, **앞 달부터 순서대로** 다시 마감합니다.
- 재마감하면 `확정/` 에 `_v2` 파일이 추가되고 `_v1` 은 그대로 남습니다.

### 4-3. 설정 변경

| 변경 | 수정 위치 |
|------|-----------|
| 사업연도 시작월 | `config.json` `fiscalYearStartMonth` |
| 표시 단위 (억원 등) | `reportUnit` · `reportUnitLabel` (예: 100000000 · 억원) |
| 사업계획 단위 | `planUnit` |
| 유지보수를 제품군별로 나누기 | `maintenanceAsGroup` = false |
| 열 이름 후보 | `orderColumns` · `salesColumns` · `pnlColumns` · `mappingColumns` · `planColumns` |
| 판정·계산 규칙 | `scripts/Invoke-PerformanceReport.ps1` → 수정 후 `run_selftest.bat` 기대값 갱신·실행, `run_sample.bat` 결과를 정답과 비교 |

> 스크립트 파일은 **UTF-8 (BOM 포함)**으로 저장해야 Windows PowerShell 5.1에서 한글이 깨지지 않습니다. 메모장은 "UTF-8(BOM)"으로 저장하세요.

## 5. 장애 대응

| 증상 | 확인 순서 | 조치 |
|------|-----------|------|
| `스크립트를 실행할 수 없습니다` | 실행 정책 | `.bat` 으로 실행 (`-ExecutionPolicy Bypass` 포함) |
| `… 열을 찾지 못했습니다` | 메시지의 실제 헤더 | `config.json` 후보에 그 이름 추가 |
| 한글이 깨진 콘솔 | 콘솔 글꼴 | 결과 파일은 정상 (UTF-8 BOM). 콘솔만 깨지면 무시해도 됨 |
| E04가 대량 발생 | `검증결과.csv` 의 제품군 이름 | 매핑에 원천제품군 추가 (같은 이름은 1건만 표시됨) |
| E07이 매달 발생 | 원장 다운로드 범위 | 마감 후에도 원장 과거 행이 바뀌는 것. 원인 확인 후 필요하면 재오픈, 아니면 당월분만 넣어 E07 방지 |
| 3개년 중 일부가 `-` | 해당 연도 원장·손익 누락 | 그 기간의 원장을 넣거나 손익 행 보완 |
| `마감이력.csv` 손상 | `.bak` | `.bak` 을 `마감이력.csv` 로 복사 (직전 상태) |
| 스냅샷 폴더 삭제 | 백업 | 백업에서 `closed/` 복구. 없으면 해당 월 재오픈 이력 추가는 불가 → 관리자가 이력의 해당 월 행을 정리한 뒤 다시 마감 |

## 6. 권한·보안

- 실적 데이터는 대외비입니다. `task/input/` · `task/output/` 은 **저장소에 올리지 않습니다** (`.gitignore` 에 포함). 저장소에는 가상의 샘플만 올립니다.
- 공유 폴더의 `input/` 쓰기 권한은 재무담당자·관리자로 제한하세요. 마감 통제는 이 권한에 의존합니다.
- 스크립트는 네트워크를 쓰지 않고 로컬 파일만 읽고 씁니다.
