# 수주·매출 실적 마감 및 경영실적 보고서 자동 생성 — 산출물 패키지

> 기준 소스: `task/scripts/Invoke-PerformanceReport.ps1` (신규 개발 v1.0)
> 작성일: 2026-10-01 · 문서 버전: v1.0

매월 수주·매출 실적을 **검증하고 마감한 뒤**, 마감 확정 데이터만으로 **경영실적 보고서(HTML·MD)와 집계표(CSV)**를 자동으로 만드는 기능입니다. 지금은 월마다 엑셀에서 수주·매출을 모으고 제품군별로 다시 나누고 3개년을 비교하는 표를 손으로 만듭니다. 이 패키지는 그 과정을 CSV 입력 한 번, 명령 한 번으로 바꿉니다. 산출물 문서, 매뉴얼, 실행 패키지를 이 폴더에 모았습니다.

## 한눈에 보는 동작

```
매월 초 (전월 마감)
 ├─ ① 원천 데이터 내려받기 → task/input/
 │     수주실적 · 매출실적 (수주잔고 관리 시스템)
 │     손익실적 (더존: 과제기여 · 인건비 · 경비 · 월말인원)
 │     제품군매핑 · 사업계획 (재무 관리 마스터)
 ├─ ② run.bat 2026-02  → 검증 + 보고서 초안
 │     ├─ 오류(E) 있으면 → 원천 수정 후 다시 실행
 │     └─ 경고(W)는 확인만 (감액 계약, 수주 없는 매출 등)
 ├─ ③ run_close.bat 2026-02  → 마감 확정 (오류 0건일 때만)
 │     ├─ 해당 월 데이터를 closed/202602/ 에 스냅샷으로 고정
 │     ├─ 마감이력.csv 에 버전·해시·실행자 기록
 │     └─ output/202602/확정/경영실적보고서_202602_v1.html
 └─ (수정 필요 시) run_reopen.bat 2026-02 "사유" → 수정 → 재마감 = v2 + 변경내역.csv
```
