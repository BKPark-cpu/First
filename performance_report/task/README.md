# 수주·매출 실적 마감 및 경영실적 보고서 Task

수주·매출·손익 CSV를 넣으면 **검증 → (마감) → 경영실적 보고서(HTML·MD) + 집계 CSV**를 만들어 주는 실행 패키지입니다.

- Windows 기본 PowerShell 5.1로 동작합니다 (별도 설치 없음, PowerShell 7 호환).
- **원본 CSV는 수정하지 않습니다.** `-Close` / `-Reopen` 을 줄 때만 `input/마감이력.csv` 와 `input/closed/` 를 바꾸고, 이력을 바꾸기 전에 `.bak` 백업을 만듭니다.
- 데이터를 외부로 보내지 않습니다.

## 폴더 구성

```
task/
├─ README.md                    ← 이 문서
├─ config.json                  ← 사업연도·단위·유지보수 처리·제품군 기준·열 이름
├─ run.bat [yyyy-MM]            ← ① 검증 + 보고서 초안 (월 생략 = 전월)
├─ run_close.bat yyyy-MM        ← ② 마감 (오류 0건일 때만)
├─ run_reopen.bat yyyy-MM "사유" ← 최근 마감월 재오픈
├─ run_sample.bat               ← 샘플 실행 (대상월 2026-02, 실행시각 고정)
├─ run_selftest.bat             ← 단위 테스트 24건
├─ scripts/
│  └─ Invoke-PerformanceReport.ps1  ← 본체 스크립트
├─ prompt/
│  └─ 경영실적보고_실행프롬프트.md   ← 스크립트 없이 Claude에게 같은 작업을 시킬 때
├─ input/                       ← 실제 운영 CSV를 넣는 곳 (마감이력·closed/ 도 여기에 생김)
└─ samples/
   ├─ input/   수주실적 · 매출실적 · 손익실적 · 제품군매핑 · 사업계획 (가상 데이터)
   └─ output/202602/            ← 샘플 실행 결과 (정답지)
```

## 빠른 시작 (샘플로 먼저 확인)

1. `run_selftest.bat` 더블클릭 → `24/24 PASS`
2. `run_sample.bat` 더블클릭
3. `samples/output/202602/요약.md` 를 엽니다. 아래 결과가 나오면 정상입니다.
   - 상태 **초안 (미마감)**, 검증 **오류 0건 · 경고 3건** (W01 감액 계약 1 · W03 수주 없는 매출 1 · W04 3월 데이터 15건 제외)
   - 2월 순수주 **1,459**백만원 (전년 동월 대비 ▲348, ▲31%) · 누계 순수주 **7,884** (▲523, ▲7%)
   - 2월 순매출 **2,526** (▲482, ▲24%) · 누계 순매출 **8,236** (▼1,613, ▼16%)
   - 누계 영업이익 **(653)** · 2월 당월 **833**
   - 누계 순수주 중 유지보수 비중 **38.7%** (전년 동기 38.8%)
4. `samples/output/202602/경영실적보고서.html` 을 브라우저로 열면 보고서 모양을 볼 수 있습니다.

## 실제 운영 절차

| 단계 | 할 일 |
|:--:|------|
| 1 | 수주잔고 관리 시스템에서 수주·매출 내역을 CSV로 내려받아 `input/수주실적.csv` · `input/매출실적.csv` 로 저장 |
| 2 | `input/손익실적.csv` 에 대상월 1행 추가 (더존 결산값) |
| 3 | `input/제품군매핑.csv` · `input/사업계획.csv` 는 바뀔 때만 수정 |
| 4 | `run.bat 2026-02` 실행 → `output/202602/요약.md` 에서 검증 결과·숫자 확인 |
| 5 | 오류가 있으면 원장을 고쳐 다시 내려받고 4단계 반복 |
| 6 | `run_close.bat 2026-02` → `output/202602/확정/경영실적보고서_202602_v1.html` 배포 |

> 같은 달 `run.bat` 은 여러 번 실행해도 됩니다. 결과 폴더만 덮어씁니다.
> 마감한 달은 이후 실행에서 **마감 당시 데이터**로 집계합니다. 원장이 바뀌어도 숫자는 그대로이고, 바뀐 사실은 E07 오류로 알려 줍니다.

## 입력 파일 형식

**수주실적.csv / 매출실적.csv**: 열 순서는 상관없고, 아래 열 이름 중 하나만 있으면 됩니다 (공백 무시). 이름이 다르면 `config.json` 의 `orderColumns` · `salesColumns` 에 후보를 추가하세요.

| 항목 | 수주 | 매출 | 필수 |
|------|------|------|:--:|
| 일자 | `수주일` `수주월` `계약일` | `매출일` `매출월` `발행일` | ● |
| PJT코드 | `PJT코드` `프로젝트코드` | 같음 | ● |
| 제품군 | `제품군` | 같음 | ● |
| 구분 | `구분` `사업구분` (`구축` / `유지보수`) | 같음 | ● |
| 금액 | `수주금액` `총수주액` | `매출금액` `공급가액` | ● |
| 차감 | `용역비`, `판매수수료` | `외주비`, `판매수수료` | |
| 기타 | `PJT명칭` `거래처` `부서` `담당` `계약번호` | `PJT명칭` `거래처` `부서` `담당` `세금계산서번호` | |

- 금액: `30,000,000` · `30000000원` · `(1,000)` · `-` 모두 됩니다.
- 일자: `2026-02-15` · `2026. 2. 15.` · `2026/02/15` · `2026-02` · `2026년 2월` 모두 됩니다. 숫자만 있는 값은 날짜로 보지 않고 오류를 냅니다.
- 인코딩: UTF-8(구글 시트 다운로드)과 CP949(엑셀 기본 저장)를 자동으로 판별합니다.

**손익실적.csv**: `월, 과제기여, 인건비, 경비, 월말인원` (월 1행). 없으면 손익·인당 지표만 빠지고 나머지는 만듭니다.

**제품군매핑.csv**: `원천제품군, 보고제품군, 적용시작월, 적용종료월, 정렬순서[, 비고]`. 원장에 나오는 모든 제품군이 있어야 합니다. 명칭이 바뀌면 행을 추가하세요 (샘플의 `전자문서 → 위변조방지` 참고).

**사업계획.csv**: `사업연도, 구분(전사/제품군/부서), 대상, 지표, 연간목표(백만원)`.

## 출력 파일 (`output/YYYYMM/`)

| 파일 | 내용 |
|------|------|
| `경영실적보고서.html` | 보고서 (Executive Summary, 전사 3개년, 목표 대비, 제품군, 부서, 인당, 추이 차트, 검증) |

## 명령줄 옵션

```powershell
.\scripts\Invoke-PerformanceReport.ps1 -InputDir <폴더> [-OutDir <폴더>] [-Month yyyy-MM]
    [-Close | -Reopen -Reason "<사유>"] [-Operator <이름>] [-Now "yyyy-MM-dd HH:mm"] [-ConfigPath <파일>]
    [-OrdersCsv <파일>] [-SalesCsv <파일>] [-MappingCsv <파일>] [-PlanCsv <파일>] [-PnlCsv <파일>] [-HistoryCsv <파일>] [-ClosedDir <폴더>]
.\scripts\Invoke-PerformanceReport.ps1 -SelfTest
```

| 옵션 | 설명 |
|------|------|
| `-InputDir` | 입력 CSV가 있는 폴더 (마감이력·closed/ 도 기본으로 여기) |
| `-OutDir` | 결과 폴더 (기본 `task/output`). 그 아래에 `YYYYMM` 폴더를 만듭니다 |
| `-Month` | 대상월 (기본 = 전월) |
| `-Close` | 마감. 실패하면 종료 코드 2 |
| `-Reopen -Reason` | 가장 최근 마감월 재오픈 (사유 필수) |
| `-Operator` | 이력에 남길 실행자 (기본 Windows 사용자명) |
| `-Now` | 실행시각 고정 (테스트·재현용) |
| `-OrdersCsv` 등 | 파일을 하나씩 따로 지정할 때 (InputDir보다 우선) |

## 스크립트 없이 쓰기 (프롬프트)

PowerShell을 쓸 수 없으면 [prompt/경영실적보고_실행프롬프트.md](prompt/경영실적보고_실행프롬프트.md) 를 Claude에 붙여넣고 CSV를 첨부하세요. 같은 규칙으로 검증하고 보고서 초안을 만듭니다. **마감(스냅샷·이력)은 스크립트로만** 하세요. 샘플로 돌린 결과가 위 정답과 같은지 먼저 확인하는 것을 권장합니다.

## 문제 해결

| 증상 | 조치 |
|------|------|
| `… 열을 찾지 못했습니다` | 오류 메시지에 실제 헤더가 나옵니다 → `config.json` 후보에 그 이름 추가 |
| `스크립트를 실행할 수 없습니다` (실행 정책) | `.bat` 으로 실행하세요 (`-ExecutionPolicy Bypass` 포함) |
| 결과 CSV 한글이 깨져 보임 | UTF-8 BOM으로 저장되어 엑셀에서 바로 열립니다. 메모장은 UTF-8로 여세요 |
| 마감이 안 됨 | 콘솔·`요약.md` 상단의 `마감 실패:` 사유 확인 (검증 오류 / 순서 / 이미 마감) |
| 전년 제품군 숫자가 예전 보고서와 다름 | 보고월 체계로 재분류했기 때문입니다 (합계는 같음). `mappingBasis` 참고 |
