# 04. 사용자 매뉴얼 — 수주·매출 실적 마감 및 경영실적 보고서

> 대상: **재무담당자(마감 실행) · 보고서 열람자** · 버전 v1.0 (2026-10-01)

---

## 1. 매월 무엇을 하나요?

전월 실적을 **검증 → 마감 → 보고서 배포** 순서로 처리합니다. 보통 매월 3~5영업일, 더존 결산이 끝난 뒤에 합니다.

| 단계 | 할 일 | 결과 |
|:--:|------|------|
| 1 | 원천 데이터 5개를 `task/input/` 에 저장 (§2) | |
| 2 | `run.bat 2026-02` 실행 | `output/202602/요약.md` · `경영실적보고서.html` (초안) |
| 3 | `요약.md` §10 검증 결과 확인 → **오류**는 원장을 고쳐 다시 내려받고 2단계 반복 | 오류 0건 |
| 4 | 초안 보고서 숫자 확인 (전월 보고서, 더존 합계와 비교) | |
| 5 | `run_close.bat 2026-02` 실행 | `확정 v1`, `output/202602/확정/` 에 확정본 |
| 6 | `확정/경영실적보고서_202602_v1.html` 배포 (PDF 인쇄 또는 파일 공유) | |

> `run.bat` 은 몇 번을 실행해도 됩니다. 마감 전에는 아무것도 고정되지 않습니다.
> `run.bat` 에 월을 쓰지 않으면 **전월**로 실행합니다.

## 2. 넣는 파일

| 파일 | 어디서 | 주기 |
|------|------|------|
| `수주실적.csv` | 수주잔고 관리 시스템 → 수주 내역 → CSV 다운로드 | 매월 |
| `매출실적.csv` | 수주잔고 관리 시스템 → 매출(세금계산서) 내역 → CSV 다운로드 | 매월 |
| `손익실적.csv` | 더존 결산값을 월 1행으로 입력 (과제기여·인건비·경비·월말인원) | 매월 1행 추가 |
| `제품군매핑.csv` | 재무 관리 마스터 | 제품군이 바뀔 때만 |
| `사업계획.csv` | 사업계획 확정값 | 연 1회 |

- 원장은 **전체 기간을 그대로** 내려받아도 되고 **당월분만** 넣어도 됩니다. 마감된 달은 마감 당시 데이터로 집계합니다.
- 처음 도입하는 달에는 3개년 비교를 위해 **전전년 사업연도 10월부터**의 원장이 있어야 합니다.
- 엑셀에서 저장한 CSV(CP949)와 구글 시트에서 받은 CSV(UTF-8) 모두 읽습니다.

## 3. 보고서 읽는 법

| 표시 | 의미 |
|------|------|
| 상태 `초안 (미마감)` | 아직 확정 전. 숫자가 바뀔 수 있음 |
| 상태 `확정 v1` | 마감된 숫자. v2 이상은 재오픈 후 다시 확정한 판 |
| 상태 `초안 — 재오픈 중` | 확정했다가 다시 연 상태. 배포하지 마세요 |
| ▲ / ▼ | 전년 같은 달(같은 기간) 대비 증가 / 감소 |
| (653) | 음수 (예: 영업손실) |
| `-` | 비교할 데이터가 없거나, 기준값이 0이라 증감률을 계산하지 않음 |
| 달성률 색 | 경과율(예: 5/12 = 41.7%) 대비 진도. 초록 = 진도 이상, 주황 = 90~100%, 빨강 = 90% 미만. 인건비·경비는 반대 |
| 유지보수 비중 | 해당 기간 TOTAL 중 유지보수 순수주(순매출) 비율 |

**용어:** 순수주 = 수주금액 − 용역비 − 판매수수료 · 순매출 = 매출금액 − 외주비 · 영업이익 = 순매출 + 과제기여 − 인건비 − 경비 · 사업연도 = 10월 ~ 다음 해 9월

| 코드 | 무엇 | 할 일 |

| E07 | 마감된 달의 원장이 바뀜 | 보고서는 마감 숫자 그대로. 바뀐 내용을 반영해야 하면 §5 재오픈 |

| E09 | 대상월 손익 행 없음 | `손익실적.csv` 에 그 달 1행 추가 |
| E10 | 대상월 수주·매출 0건 | 파일·대상월을 확인 |
| W01 | 음수 순수주·순매출 | 감액 변경계약, 마이너스 세금계산서가 맞는지 확인 (마감 가능) |
| W02 | 비용 > 금액 | 용역비·외주비 입력이 맞는지 확인 |
| W03 | 매출 PJT가 수주에 없음 | PJT코드 오입력 또는 수주 등록 누락 확인 |
| W04 | 대상월 이후 데이터 | 다음 달 데이터라 이번 보고에서 뺌 (정상) |

## 5. 마감 후 고쳐야 할 때

1. `run_reopen.bat 2026-02 "2월 매출 1건 누락"` — **사유를 꼭** 적습니다. 가장 최근에 마감한 달만 열 수 있습니다.
2. 원장을 고치고 다시 내려받아 `run.bat 2026-02` 로 확인합니다 (`재오픈 중` 표시).
3. `run_close.bat 2026-02` → `확정 v2`. `output/202602/변경내역.csv` 에 v1 대비 추가·삭제된 행이 남습니다.
4. v2 보고서를 다시 배포하고, 받는 사람에게 "v1 대체"라고 알립니다.

> 1월을 고쳐야 하는데 2월까지 마감했다면 **2월 → 1월 순서로 재오픈**하고, 1월 → 2월 순서로 다시 마감합니다. 1월이 바뀌면 2월 누계도 바뀌기 때문입니다.

## 6. 자주 묻는 질문

**Q. 숫자가 전월 보고서와 다르게 나왔어요.**
그 달이 이미 마감되었다면 보고서는 마감 숫자를 씁니다. 마감 전이라면 원장이 그사이 바뀐 것입니다. `검증결과.csv` 와 원장 내려받은 날짜를 확인하세요.

**Q. 전년 실적이 예전 보고서와 제품군별로 달라요.**
기본 설정은 **지금 제품군 체계로 과거 실적까지 다시 나눕니다**. 예를 들어 예전 `전자문서` 실적이 `위변조방지` 행에 들어갑니다. 합계는 같습니다. 예전 체계 그대로 보려면 관리자에게 `mappingBasis` 변경을 요청하세요.

**Q. 3개년 중 한 해가 `-` 로 나와요.**
그 기간 중 데이터가 없는 달이 있습니다. 해당 연도 원장을 함께 넣어 주세요.

**Q. 인당 지표가 안 나와요.**
`손익실적.csv` 의 `월말인원` 이 누계 기간의 어느 달이든 비어 있으면 생략됩니다.

**Q. 보고서를 PPT로 만들어야 해요.**
HTML을 브라우저에서 열어 표를 복사하거나, 인쇄 → PDF 저장을 쓰세요. 집계 CSV(원 단위)를 엑셀 차트 원본으로 써도 됩니다.
